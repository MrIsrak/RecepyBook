# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для последней минорной версии.

| Версия | Поддержка |
|---|---|
| 1.1.x | ✅ |
| 1.0.x | ❌ |

## Как сообщить об уязвимости

Не открывай публичный issue. Используй [приватное сообщение об уязвимости](https://github.com/MrIsrak/RecepyBook/security/advisories/new).

Опиши проблему, шаги воспроизведения и возможное влияние. Ответ — в течение 7 дней.

## Что важно знать

- Ключ Gemini хранится в DataStore внутри песочницы приложения и отправляется только на `generativelanguage.googleapis.com`.
- Приложение не открывает входящих соединений и не собирает аналитику.
- Ключ подписи релизов хранится только в секретах GitHub Actions и никогда не коммитится.
