# Support

## Getting help

1. **Check the documentation:** [README](README.md), and [docs/IMPORT.md](docs/IMPORT.md) for import troubleshooting.
2. **Search existing issues:** someone may have reported the same thing.
3. **Open an issue** using the [templates](https://github.com/MrIsrak/RecepyBook/issues/new/choose). Issues may be written in English, Russian or Hebrew.

## Before reporting an import problem

- Make sure the post is public and opens without signing in.
- Wait a minute and try again. Social networks temporarily rate-limit requests.
- Try pasting the caption text directly into *Add recipe → From a link* (plain text is parsed too).
- Include the exact link in your report.

## Scope

RecepyBook is maintained on a best-effort basis by volunteers. There is no guaranteed response time for general questions. Security reports follow the timelines in [SECURITY.md](SECURITY.md).
