# Архитектура

## Слои

```
ui (Compose)  →  data (Repository, Room, DataStore)  →  core (чистый Kotlin)
      ↓                         ↑
   importer (сеть, ML Kit, Gemini)  ──────────┘
```

- **core** — без зависимостей от Android, покрыт unit-тестами:
  - `IngredientParser` — строка → количество / диапазон / единица / название / пометка («по вкусу»). Количество может стоять в начале или в конце строки, понимает дроби `½`, `1 1/2` и иврит.
  - `CaptionParser` — подпись поста → название, ингредиенты, шаги, порции, время. Ищет заголовки разделов (в том числе посреди строки), а без заголовков работает эвристикой. Отрезает хвост с хэштегами и призывами подписаться.
  - `Units` / `QtyFormat` — единицы и пересчёт, красивый вывод дробей.
  - `NutritionDb` — таблица продуктов (основы слов на трёх языках): КБЖУ на 100 г, вес штуки, плотность, отдел магазина.
- **importer**
  - `LinkImporter` — определяет платформу и вызывает нужную стратегию:
    - TikTok — oEmbed API;
    - Instagram — embed-страница с подписью и og-теги как запасной вариант;
    - YouTube — oEmbed и `shortDescription` со страницы;
    - Pinterest — переход на исходный сайт;
    - сайты — JSON-LD `schema.org/Recipe`, без него текст статьи.

    Потом при наличии ключа идёт Gemini, иначе `CaptionParser`, а в конце расчёт КБЖУ.
  - `PhotoImporter` — Gemini (если есть ключ) или ML Kit OCR.
  - `GeminiClient` — REST `generateContent` со структурированным JSON-ответом.
- **data** — Room: `recipes`, `cookbooks`, `recipe_cookbook`, `meal_plan`, `grocery`. Ингредиенты хранятся как JSON-колонка. Картинки копируются в `filesDir/images`, потому что ссылки CDN соцсетей со временем протухают.
- **ui** — один `Activity` и Navigation Compose: 4 вкладки (Рецепты, План, Покупки, Книги) и экраны рецепта, готовки, импорта, редактора, настроек.

## Решения

| Решение | Почему |
|---|---|
| Без сервера | Бесплатно навсегда, приватно, работает офлайн |
| Gemini — опция с ключом пользователя | Бесплатный тариф Google, у проекта нет расходов |
| Ручной DI (`AppContainer`) | Мало зависимостей, Hilt для такого размера избыточен |
| JSON-колонки вместо таблицы ингредиентов | Ингредиенты всегда читаются вместе с рецептом |
