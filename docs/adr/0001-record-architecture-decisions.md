# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-15

## Context

The project needs a lightweight, durable record of why key technical choices were made, so that contributors can understand the constraints without reconstructing history from commits.

## Decision

Significant decisions are recorded as Architecture Decision Records in `docs/adr/`, numbered sequentially and written in English.

## Consequences

Decisions become reviewable in pull requests and discoverable later. The log has to be kept up to date as part of the definition of done for architectural changes.
